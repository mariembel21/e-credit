
# E-Credit – Credit Request Management App

E-Credit is a full-stack web application that allows users to submit, track, and manage credit requests digitally.  
It is designed for efficiency, transparency, and collaboration between clients and credit officers.
## Features
- **New Credit Request Form** – Users can submit requests with required attachments.
- **Requests Consultation** – View, search, and filter all submitted requests.
- **Status Tracking** – Follow-up and decision history for each request.
- **Guarantees & Attachments** – Full support for managing related documents.
- **Secure Backend** – Built with Node.js, Express, and Drizzle ORM.
## Tech Stack
- **Frontend:** React + Chakra UI
- **Backend:** Node.js, Express, Drizzle ORM, PostgreSQL
- **File Storage:** Local file uploads (attachments)
